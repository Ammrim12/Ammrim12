## 👨‍💻 Sobre mim

Sou **Analista de Desempenho Industrial** e estudante de **Bacharelado em Sistemas de Informação**, com interesse na integração entre processos industriais, análise de dados e desenvolvimento de software.

Minha experiência profissional no ambiente industrial contribui para uma visão prática sobre indicadores de desempenho, organização de informações, análise de processos e identificação de oportunidades de melhoria.

Atualmente, direciono meus estudos e projetos para o desenvolvimento de soluções que transformam necessidades operacionais em sistemas, dashboards e ferramentas de automação.

Tenho interesse especial em:

- Desenvolvimento de aplicações com Python.
- Análise, tratamento e visualização de dados.
- Criação de dashboards e interfaces interativas.
- Automação de tarefas e processos.
- Desenvolvimento de APIs e sistemas de gestão.
- Bancos de dados e organização de informações.
- Aplicação da tecnologia à melhoria do desempenho operacional.

**Meu objetivo:** unir conhecimento de processos, raciocínio analítico e desenvolvimento de software para construir soluções úteis, organizadas e orientadas a dados.

## 🚀 Projetos em destaque

### 📈 AeroQuant B3 — Terminal de análise do mercado financeiro

Dashboard financeiro desenvolvido com **Python e Reflex**, voltado à exploração de ativos da Bolsa brasileira e à visualização de informações do mercado financeiro.

**Principais funcionalidades documentadas:**

- Explorador de ações, fundos imobiliários (FIIs), ETFs e BDRs.
- Mapa de calor para visualização do desempenho dos ativos.
- Gráficos e indicadores de mercado, incluindo média móvel de 20 pregões.
- Gestão de carteira e comparação de desempenho com Ibovespa e CDI.
- Calendário de eventos financeiros e central de notícias.
- Exportação de dados da carteira para CSV.
- Testes automatizados com Pytest e integração contínua com GitHub Actions.

**Tecnologias:** Python, Reflex, integração com fontes de dados financeiros, Pytest e GitHub Actions.
