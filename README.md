
## Projetos em destaque

### 📈 AeroQuant B3 — Inteligência de Mercado Financeiro

Dashboard interativo desenvolvido em Python e Reflex para explorar o mercado financeiro brasileiro e transformar dados de mercado em informações visuais para análise.

**Principais funcionalidades:**
- Explorador de ações, FIIs, ETFs e BDRs da B3.
- Mapa de calor para análise visual do mercado.
- Dashboard com indicadores e gráficos financeiros.
- Gestão de carteira e comparação com Ibovespa e CDI.
- Calendário de eventos financeiros e central de notícias.
- Testes automatizados e integração contínua com GitHub Actions.

**Tecnologias:** Python, Reflex, Pandas, integração com fontes de dados financeiros e Pytest.
